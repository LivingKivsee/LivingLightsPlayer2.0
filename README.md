# Living Lights Player 2.0
xLights software LED animation shows played on Teensy boards with music synchronization

**xLight Installation:**
Download the latest version of xLights from https://xlights.org/

**xLights Controllers** \
There are two supported Ethernet protocols: DDP or E1.31 \

The E1.31 setup require a single controller with a sufficient number of universes \
Each universe is up to 170 LEDs (a dmx universe) and can't be spread over different output ports \
This means Number Of Universes = Number of Output Ports * ceil(Number of LEDs in port / 170) \
o create the controller in xLights Controllers tab:
1) press the "Add Ethernet" button
2) Set IP address to 127.0.0.1 (localhost)
3) Set the required Universe Count

For DDP setups, a controller is needed for each output port \
To create the controllers in xLights Controllers tab:
1) press the "Add Ethernet" button
2) Set Protocol to DDP
3) Set controller 1 IP address to 127.0.0.1 (localhost), controller 2 to 127.0.0.2 and so on

**xLights Layout:**
1) Add a background image of the installation for convenience, not mandatory 
2) Add LED objects using the models toolbar located above the image
3) For each model shape choose the number of Nodes/String - the number of LEDs in the shape
4) Choose Start Channel - as Universe/Controller Number or End of Model of previous object
5) For E1.31 Protocol setups, in objects Controller Connection - choose dmx protocol and port 1, set the dmx channel according to universe number of the string

# Python ll-sacn-recorder
A python script project, originally develeoped by Amir Blum, is used to record xLights output and played by the Living Lights Player. \
Player 2.0 uses the forked version by Oren Bigler and can be found here: https://github.com/bigoren/ll-sacn-recorder  
For usage instructions of the capture.py or capture_ddp.py scripts, see the recorder project documentation.

# Teensy
A Teensy board (version 4.1) with builtin SD card support and an OctoWS2811 shield plays the recorded python script output file.  
Music is played by another Teensy board using an audio shield and audio library and synced to the LEDs playing Teensy over IOs.

## ll-teensy-player library
A Teensy library for playing data frames from an SD card on LEDs, originally developed by Amir Blum and forked by Oren Bigler,
is used by the Living Lights Player and can be found here: https://github.com/bigoren/ll-teensy-player

## Library Installation
Arduino IDE: download the library as zip, open Arduino IDE and go to Sketch -> Include Library -> Add .ZIP library...  
VSCode with PlatformIO: The platformio.ini lib_deps field automatically fetches the required libraries, see platformio.ini file.

## Library Usage
Load a microSD card with library compatible files, these can be generated by the python recorder script.  
To use the library the Living Lights Player includes it, #include "SdLedsPlayer.h", and defines an object of type SdLedsPlayer.
Goto File -> Examples -> ll-teensy-player for several examples of library usage.

# Player Filenames and features
* LED data files should be must 1, 2, 3 .. 12 for up to 13 files automatically played in a loop
* Files 13, 14, 15 are played according to triggers by IO events on pins 0, 1, 17 respectively
* Audio filenames should be 1.wav, 2.wav, 3.wav .. 15.wav to match the LED data files
* The LED playing Teensy can be reset by triggering an event on pin 3.
* Next and Previous file playing can be triggered using pins 4 & 15 respectively.
* A sensor example of an Arduino with an RFID reader triggering an IO event can be found under the Sensors directory
